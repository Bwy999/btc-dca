# V28.2.2 · 波动增币简明版

基线：用户提供的 SatsGarden V28.2.1。此次修改了 VHE 前端页面、样式、渲染及简易设置逻辑，并重新构建哈希资源，统一页面与 SW 构建号。未修改原 VHE 算法、实际账本、URPD、历史种子或自动行情任务；未部署网站。

## 默认使用方式

1. 打开定投页的「波动增币」。先看结论和相对长期持有的币量差额。
2. 查看相对单位投入成本（同样的正投入下，基准期末币量 / 策略期末币量 - 1）。有待回购现金时，明确按期末参考价折算，非实际持币量或税务成本。
3. 查看为何得到结论。另选的历史候选策略与当前自定义回测分开解释；不把滚动窗口胜率当成未来概率。
4. 「调整模拟」仅修改起始 BTC、日期与波段比例；提交后重新回测。修改起始币量时清空不再适用的起始美元成本，仅影响模拟设置。其他配置保持不变。研究页有未应用修改时，阻止简易设置覆盖。完整研究与原有详细图表按需打开。

## 默认示例结果（真实内置历史数据，非实时信号）

2021-11-01 至 2026-09-26，初始 0.3 BTC，10% 波段仓，未额外入金：长期持有 0.300000 BTC；波段 0.296236 BTC；相对差额 -0.003764 BTC（-1.25%），相对单位投入成本 +1.27%。独立 5% 候选策略的 24 个月滚动历史窗口跑赢比例 24.44%，不是当前 10% 策略的胜率。含模拟手续费与滑点，未计税费。
