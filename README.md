## 核心能力

### AHR999 · 首页的估值坐标

AHR999 是这个项目的精神原点。

- **两种模型**：2026 新拟合与 2018 经典版一键切换，数值、走势、分区价格同步变化
- **固定分界**：0.45 深度低估 · 1.2 低估区上沿 · 5 高估风险
- **走势图**：30 日 / 90 日 / 1 年 / 全部，按住图表查看任意一天的收盘指数
- **分区价格**：深度低估边界、周期中轴、低估区上沿分别对应多少美元

### 价格关键位 · 支撑在哪里、有多厚

把散落在各处的关键价位汇聚到一张图里：

| 分组 | 包含 |
|:---|:---|
| **AHR999** | 深度低估线、低估区上沿 |
| **链上成本** | Active Price、True Market Mean、STH 实现价格、C50 中位成本 |
| **资本化价格** | STH / LTH / 全市场资本化价格 |
| **底价模型** | Bedrock p95 / p99 / p99.5、F5 / F2 压力底 |
| **幂律模型** | 幂律支撑、幂律公允价 |

左轴按真实价格比例排列，刻度是相对现价的距离；竖轴上的密度光带直观显示支撑最厚的区域。开头一句话自动总结「最近的支撑」和「最厚的一层」，点按任一条线可查看含义与数据日期。

### 分析 · 看清结构

- **七维估值**：AHR999、价格 / 200 周均线、MVRV、恐惧贪婪、Puell Multiple、Reserve Risk、SOPR，按数据新鲜度动态校准
- **周期顶部回撤**：五轮周期对齐到顶部第 0 天，对比当前回撤深度与持续时间
- **幂律走廊**：支撑、公允、阻力三条长期模型线，以及现价在走廊中的位置
- **双底价系统**：Bitview 十模型共识底价与 UTXO 成本底价带交叉验证

### 链上 · 看懂持币者

- **周期底部探索**：MVRV 跌破 1、跌破短期持有者成本与 True Market Mean、长期筹码大面积浮亏、长期持有者亏损卖出、Puell < 0.5、AHR999 < 0.45、触及共识底价，清点亮起几个底部信号
- **周期顶部探索**：MVRV-Z > 7、AHR999 ≥ 5、Pi Cycle 顶部交叉、触及幂律阻力、老筹码集中卖出、盈利供应 > 95%、Puell > 4，清点亮起几个顶部信号
- 每个信号都显示当前值、触发阈值、离触发还差多少，以及历史上每一次触发的年月；只清点信号，不预测底部或顶部

- **成本结构状态机**：扩张 → 测试 → 压缩 → 去杠杆 → 投降 → 收复，与预设执行规则对照
- **成本线**：STH 实现价格、True Market Mean 与 STH / LTH / 全市场资本化价格
- **长期持有者**：亏损供应、筹码集中度 ±10%、花费脉冲与 NUPL
- **筹码分布与深度亏损**：URPD 分布、亏损供应与持币群体迁移
- **矿工与网络**：算力、难度、矿工关机价、均衡价、Puell Multiple 与减半倒计时

| 数据 | 来源 |

| 实时价格 | Binance、OKX、Coinbase 三源交叉校验 |
| 历史价格与矿业 | mempool.space、Blockchain.com |

**诚实是第一原则：**

- 每个模块都标注数据日期，超过 3 天未更新会明确标出「滞后」
- 接口失败时保留已有数据并说明原因，**从不用模拟数据填补空白**
- 内置「数据健康中心」，可随时查看每个来源的状态、日期与失败原因
- 数据来源与计算口径写在各模块的「指标说明」里

## 自行部署

纯静态网站，无需服务器端程序、数据库或构建步骤。把以下文件放到任意静态托管（GitHub Pages、Cloudflare Pages、Nginx 等）即可：

| 文件 | 用途 |
|:---|:---|
| `index.html` | 主页面，单文件包含全部界面与逻辑 |
| `sw.js` | Service Worker，负责离线缓存与版本更新 |
| `ahr999.html` | AHR999 致敬与模型研究专页 |
| `dca.html` | 独立定投页面 |
| `apple-touch-icon.png` | 主屏幕图标 |

本地预览：

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

更新网站时，`index.html` 与 `sw.js` 需要一起替换，并建议最后上传 `sw.js`。更新后可在「分析 → 数据健康中心」核对版本。
